## Compiler

### Usage (for linux)

#### Compile the compiler

```
gcc kamenpapier.c -o kamenpapier
```

#### Compile and run Praskscript

```
./kamenpapier example.psc
```

#### Debug
For debugging, define the DEBUG macro trough gcc flag

```
gcc kamenpapier.c -o kamenpapier -D DEBUG
```
